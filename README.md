# Portfólio Pessoal — Alura Include

## 🇧🇷 Português

Este projeto é um site de portfólio pessoal desenvolvido durante o programa **Alura Include**.

O objetivo foi colocar em prática conceitos de desenvolvimento Front-End, criando uma página pessoal para apresentar minha trajetória, habilidades e formas de contato.

### Sobre o projeto

O site apresenta:

* Página inicial com uma breve apresentação;
* Seção "Sobre mim";
* Seção de habilidades;
* Área de contato;
* Links para GitHub e LinkedIn;
* Design responsivo para diferentes tamanhos de tela.

### Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

### Programa

Projeto desenvolvido como parte do programa **Alura Include**, uma iniciativa voltada à formação e desenvolvimento de novos profissionais na área de tecnologia.

### O que pratiquei

Durante o desenvolvimento deste projeto, pude praticar conceitos importantes de desenvolvimento Front-End, incluindo:

* Estruturação de páginas com HTML;
* Estilização e organização visual com CSS;
* Criação de interações utilizando JavaScript;
* Desenvolvimento de interfaces responsivas;
* Organização de um projeto para publicação na web;
* Utilização do Git e GitHub para versionamento e portfólio.
